LLM Limitations and Safeguards

Common Limitations

1. Knowledge Cutoff: An LLM may not know recent events or changes.
2. Hallucination: An LLM may generate incorrect or fabricated information.
3. Context Length: An LLM has a maximum amount of text it can process in one request.
4. Reasoning Errors: An LLM may make mistakes in calculations or logical problems.

Five Safeguards

1. Verify Important Facts: Check important claims against trusted and official sources.
2. Use Clear Prompts: Specify the task, constraints, and expected output format.
3. Validate Structured Output: Check generated JSON against a schema before using it.
4. Test Generated Code: Run unit tests and review code before deployment.
5. Protect Sensitive Data: Avoid sending confidential or personal information to an LLM unless the system is approved for that use.

Experiment Summary

The experiments tested current-information handling, hallucination risk, retrieval from a longer text, and reasoning accuracy. Results apply only to the prompts and model used in these tests; they do not guarantee that the model will always behave the same way.
