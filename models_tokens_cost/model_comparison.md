Recommendation

1. Public Customer-Support Bot

I recommend a hosted GPT model suitable for customer-support workloads. A hosted model can provide managed infrastructure, API integration and structured output capabilities. The final model should be selected after comparing accuracy, latency, pricing and privacy requirements.

2. Private On-Premise Tool

I recommend a suitable Meta Llama open-weight model. It can be deployed on company-controlled infrastructure, subject to hardware requirements and the applicable license. This gives the company greater control over data handling and deployment.
